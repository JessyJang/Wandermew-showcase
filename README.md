# Wandermew · 漫游海鸥

一场关于飞翔、停留，以及去码头整点薯条的交互实验。

![漫游海鸥项目封面](cover.png)

*项目概念封面，非游戏实机截图。*

## 在这里，放空，是唯一被允许的正事

我们终其一生都在飞。去不同的地方，触碰不同的人和事，停留一段时间，然后离开。也许还没找到答案，又被另一件美好的小事分散了注意力。

Wandermew「漫游海鸥」是人类助理Jessy 和 GPT-6 一起完成的交互实验。以 Wayfinder 的形式，将“去码头整点薯条”这个荒诞网络对话重新解构，演化成了一片可以自由探索的数字海岸。

在这场探索里，一只海鸥，坠入由青绿海水、低饱和礁石和暖黄草地交织的海岸世界。踩过草地草会弯，靠近潮池鱼会跳，跑向螃蟹它会溜，可以收集触碰散落的海岸手记碎片道具，或者是静静地停在码头看海。

生活的宏大问题常常没有答案，但一个荒诞却具体的小目标，就能成为对抗虚无的锚点。去哪里不重要，先飞起来才重要。如果你也不知道要飞向何方，不如「去码头，整点薯条」。

## 海岸上的小事

- **借一阵风起飞。** 从沙洲出发，在岛屿之间漫游。
- **翻过一张小票。** 背面有人写着：“我在旧码头等你，老伙计。”
- **放走一条小鱼。** 手记里留下的不是战利品，而是“小鱼的吻”。
- **把心情交给旧钥匙。** 一句话，或者一个词，把此刻留在岛上。
- **与月亮合影。** 为一次偶然的停留，留下一张照片。
- **在码头遇见老伙计。** 一起吃薯条，或者一起看海。

没有必须集齐的清单。收集与停留，都不是通关的条件。

## 这个项目在探索什么

生活的宏大问题常常没有答案，但一个荒诞却具体的小目标，可以成为对抗虚无的锚点。

我们希望交互不只是点击后出现一段话，而是一点可感知的回应：脚步经过，草会弯；靠近潮池，鱼会跳；跑向螃蟹，它会溜。风景不只是背景，它也回应你的到来。

这个实验也记录着人与 AI 的协作：从故事、视觉方向，到角色动作、声音和界面的反复打磨。AI 参与制作，人来选择什么值得留下。

## 作品构成

以下是功能概览，不是源代码目录。

| 部分 | 内容 |
| --- | --- |
| 海岸世界 | 岛屿、路径与自由探索 |
| 海鸥动作 | 行走、起飞、振翅、滑翔与落地 |
| 相遇与道具 | 发现、触碰、选择与回应 |
| 海岸手记 | 收藏、心情与照片 |
| 声音与光影 | 音乐、环境声和场景氛围 |
| 叙事序章 | 从首页进入海岸的开场体验 |

## 进展

项目持续打磨中，已归档至 **薯条 v1.0.3**。近期工作包括海鸥动作、序章衔接、道具插画、交互反馈与对话排版。

本仓库仅用于作品展示，不提供可运行的游戏版本。源代码、完整素材库和内部开发文档保留在私有仓库。
